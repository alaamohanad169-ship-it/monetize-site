🔬 What I Customized on Hermes Agent

ARM64 / Termux Compatibility

First Fix

Resolved bionic libc vs glibc conflicts. ELF binaries built for standard Linux can't run on Termux — I patched the install scripts and documented workarounds for Android ARM64.

Venv Path Resolution

Path Fix

The codebase referenced .venv but Termux uses venv (no dot). Created symlinks and updated config to handle both cases automatically.

Python 3.12 + Package Fixes

Compat Layer

Fixed deprecated pkg_resources imports, updated dependencies for Python 3.12, resolved --only-binary failures by switching to system packages where possible.

Git Author & Fork Cleanup

Identity

Rewrote all personal commits under "Spider-Verse" identity using surgical rebase. Kept upstream commits intact to preserve fork relationship and enable future pulls.
